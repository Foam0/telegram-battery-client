# Security policy

Please do not open a public issue containing a VLESS profile, Telegram API
credentials, Firebase server credentials, signing keys, phone numbers, login
codes, or session data.

VLESS profiles are runtime user data and must never be committed to this
repository. The checked-in sample configurations use non-routable documentation
addresses and unusable credentials.

For a sensitive report, use GitHub's private vulnerability reporting for this
repository. Rotate any credential that was exposed before reporting it.
